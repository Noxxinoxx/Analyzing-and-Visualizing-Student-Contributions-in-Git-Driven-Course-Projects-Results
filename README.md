# Analyzing and Visualizing Student Contributions in Git-Driven Course Projects – Results

This repository contains the supplementary material and result files used in the thesis *Analyzing and Visualizing Student Contributions in Git-Driven Course Projects*.

## Files

### GUMTREE-vs-LOC-Results.ods

Contains the collected data and analysis results used for the comparison between LOC-based and GumTree-based differencing approaches presented in RQ1.

### Interview-Questions.pdf

Contains the interview guide used during the evaluation of the automation tool.

### Interview-Compiled-Answers.pdf

Contains the compiled responses from the interviews conducted during the evaluation of the automation tool.
